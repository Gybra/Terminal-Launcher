# Open system Overview Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open Android's system Overview from a registered `overview` command and from a swipe up in the lower half of Home, reusing the existing accessibility service.

**Architecture:** `Overview.open()` is the one Android boundary (`GLOBAL_ACTION_RECENTS`). Gestures on Home emit events; `OverviewCommand` calls the same boundary and returns `CommandResult.OpenOverview` on success or an output line on failure. Compose does not branch on shell. Origin: `docs/superpowers/specs/2026-09-04-overview-design.md`.

**Tech Stack:** Kotlin, Jetpack Compose, Robolectric, JUnit 4, existing command registry and accessibility service.

## Global Constraints

- Origin spec R1–R10 and its scope boundaries are in force; do not list recents, kill apps, or widen the accessibility service.
- Minimum SDK API 28; no new permissions, dependencies, or settings toggles.
- Unavailable copy is `overview unavailable` (DOS: `OVERVIEW UNAVAILABLE` via `formatMessage`).
- Command description must be ≤ 23 characters (`LauncherCommandsTest`).
- Public boundary types: explicit visibility and explicit non-`Unit` return types. No `!!` outside tests.
- One principal public type per file. English names and KDoc.
- Required gate before the branch is done: `./gradlew testDebugUnitTest koverVerifyDebug lintDebug assembleDebug`.
- Do not regenerate README screenshots unless a screenshot test fails.

`pointerInput(onExpandNotifications, onExpandQuickSettings, onOpenOverview)` calls a renamed detector:

```kotlin
private suspend fun PointerInputScope.detectHomeSwipe(
    onNotifications: () -> Unit,
    onQuickSettings: () -> Unit,
    onOverview: () -> Unit,
) {
    awaitEachGesture {
        val down = awaitFirstDown(
            requireUnconsumed = false,
            pass = PointerEventPass.Initial,
        )
        val start = down.position
        val end = awaitSwipeEnd(pointerId = down.id, start = start)
        if (!isHomeSwipe(start = start, end = end)) {
            return@awaitEachGesture
        }
        val dy = end.y - start.y
        when {
            dy < 0f -> onOverview()
            start.x < size.width / 2f -> onNotifications()
            else -> onQuickSettings()
        }
    }
}
```

`awaitSwipeEnd` must consume only lower-half vertical moves (it currently consumes every downward move). It needs the Column size: pass `size.height` into it, or keep it as an extension on `PointerInputScope` by inlining the loop in `detectHomeSwipe`. Consume when:

```kotlin
val dy = current.y - start.y
val inLowerHalf = start.y >= size.height / 2f
if (inLowerHalf && abs(dy) > slop && abs(dy) > abs(current.x - start.x)) {
    change.consume()
}
```

`isHomeSwipe`:

```kotlin
private fun PointerInputScope.isHomeSwipe(start: Offset, end: Offset): Boolean {
    val dy = end.y - start.y
    return start.y >= size.height / 2f &&
        abs(dy) > viewConfiguration.touchSlop &&
        abs(dy) > abs(end.x - start.x)
}
```
